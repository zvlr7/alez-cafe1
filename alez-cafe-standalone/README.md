# كافيه الز - Al-Z Cafe Website

موقع احترافي لكافيه الز مصمم بـ HTML و CSS و JavaScript بشكل منفصل وسهل الاستخدام.

## 📁 الملفات المتضمنة

```
alez-cafe-standalone/
├── index.html      # الصفحة الرئيسية (HTML)
├── styles.css      # أنماط التصميم (CSS)
├── script.js       # الوظائف التفاعلية (JavaScript)
└── README.md       # هذا الملف
```

## 🚀 كيفية الاستخدام

### الطريقة الأولى: فتح الملف مباشرة
1. انسخ جميع الملفات إلى مجلد واحد
2. افتح ملف `index.html` في متصفحك
3. الموقع سيعمل فوراً بدون الحاجة لخادم

### الطريقة الثانية: استخدام خادم محلي (موصى به)
```bash
# باستخدام Python 3
python -m http.server 8000

# أو باستخدام Node.js
npx http-server
```
ثم افتح: `http://localhost:8000`

## 📝 التعديلات الممكنة

### تغيير الألوان:
عدّل المتغيرات في أعلى ملف `styles.css`:
```css
:root {
    --coffee-brown: #8B6F47;  /* غيّر هنا */
    --coffee-gold: #D4AF37;   /* غيّر هنا */
    /* ... إلخ */
}
```

### إضافة منتجات جديدة:
في ملف `index.html`، أضف عنصر جديد:
```html
<div class="menu-item">
    <div class="item-header">
        <h4>اسم المنتج</h4>
        <span class="price">السعر ر.س</span>
    </div>
    <p class="item-description">وصف المنتج</p>
</div>
```

### تغيير معلومات التواصل:
ابحث عن قسم Contact في `index.html` وعدّل المعلومات
